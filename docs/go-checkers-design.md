# 围棋与空跳跳棋扩展

用户确认跳棋支持空跳（对称跨越一枚棋子，两侧空位数相同），每回合可连续跳同一枚棋子。

- 围棋2人，房主在准备阶段选择9/13/19路，默认19路。黑先，白贴7.5点，按棋子与围空总和计算面积。禁止自杀和重复全盘局面；连续两次停手进入死子确认阶段，任何修改撤销双方确认，双方确认同一状态后结算。有争议可恢复对弈，支持认输。
- 跳棋121孔星形棋盘，每人10枚，支持2/3/4/6人（5人不出现在筛选结果且不能开局）。单步邻移或以一子为中点的对称空跳；连续跳需用同一子，不重复落点，不吃子；进入目标营地后不能离开。先将10枚全部进入对面营地者胜。无合法移动才允许跳过；退出比赛移除该方棋子，剩一方胜。
- 共用现有昵称、房间、准备、轮次、版本并发保护和cookie恢复。棋盘尺寸变更取消全员准备，服务端校验。
- 沿用花生壳域名和本地8787服务，不向之前不可访问的Sites公网地址重新发布。
