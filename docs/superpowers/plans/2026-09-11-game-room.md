# Game Room Implementation Plan

**Goal:** 可在不同设备同房游玩的三款游戏。
**Architecture:** React大厅/房间/游戏视图；纯函数规则；服务端身份验证、私密投影与版本更新；D1存储。
**Tech Stack:** TypeScript, React, Vinext, Cloudflare D1.

## Global Constraints
中文、手机电脑响应式。首页默认全部，人数过滤2～6。服务端判断，不把他人手牌/词发给浏览器。

### 1. 大厅
- [ ] `app/page.tsx`, `app/globals.css`, `app/layout.tsx`, `public/favicon.svg`：奶油底、深绿品牌、三张可触控游戏卡片，底部人数选择，创建/加入表单。
- [ ] 检查全部/2/3/4/5/6筛选数量为3/1/1/1/1/1，移动端不横向溢出。

### 2. 规则
- [ ] `tests/games.test.ts` 先覆盖落子越权/五连、斗地主飞机/王炸/非法牌/过牌、卧底秘密信息/轮流描述/平票/胜负。
- [ ] `lib/games.ts`, `lib/cards.ts` 提供创建、行动、玩家可见视图，执行 `node --experimental-strip-types --test tests/games.test.ts`。

### 3. 房间服务
- [ ] `db/schema.ts`, `lib/rooms.ts`, `app/api/room/route.ts`：房间创建、加入、准备、开始、行动、恢复、离开、更换；身份凭证从HttpOnly cookie获得；读取私密投影。
- [ ] 条件UPDATE使用版本号，不允许重复回合操作；接口测试覆盖未加入、满员、非法动作和并发冲突。
- [ ] 生成迁移，构建并本地应用SQL。

### 4. 对局界面
- [ ] `app/game-room.tsx`：玩家准备/分享/房主控制；棋盘；扑克牌选择和叫分出牌；卧底看词/描述历史/投票/结算。
- [ ] 游戏房间每秒读取服务端，断网提示并恢复，动作后立即刷新。

### 5. 验证交付
- [ ] 规则测试、类型检查、生产构建、多会话完整对局测试；检查手机与桌面。
- [ ] 保存来源说明、运行说明、验证结论；根据Sites能力发布并确认访问范围。
