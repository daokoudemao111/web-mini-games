# 一局：好友游戏室

用户已确认首版范围。手机和电脑通过同一房间在线游玩，免注册，输入昵称加入。

首页默认显示全部三款游戏；底部固定「全部、2人、3人、4人、5人、6人」。2人筛选五子棋，3人筛选斗地主，4～6人筛选谁是卧底。筛选不决定实际房间人数。

房主选择游戏创建房间，分享房间码或链接；全员准备后开始。结算可以再玩或更换游戏。服务端持有唯一权威状态，校验行动、轮次、玩家身份；浏览器只收到自己可见的信息。使用服务器生成的私密座位凭证恢复身份，不把凭证放在邀请链接内。

五子棋：15×15，黑先，至少连五获胜，无禁手，认输、双方同意悔棋，再开交换先手。

斗地主：54张牌，17张每人加3张底牌；轮流叫0～3分，最高分为地主，全不叫重新发牌。单、对、三张、三带一/对、顺子、连对、飞机及带翅膀、四带二/两对、炸弹、王炸。两家连续不出后清空当前牌型，由上家先出。地主手牌清空则地主胜，任一农民清空则农民胜；房间内娱乐计分。

谁是卧底：4～6人，1卧底，无白板；各自查看词语，不显示自身阵营。存活玩家依次在网页提交一句描述，之后同时秘密投票，不投自己。统一公布票数，最高票淘汰；平票者补充描述，所有存活玩家重投，仍平票无人淘汰。卧底出局平民胜；卧底活到剩2人则卧底胜。出局者只读观战，结算揭晓词对和身份。

首版不包含账户、排行榜、语音、AI陪玩。对局状态持久化，刷新能恢复；网络失败提示重试并保留输入。

## GitHub 参考（2026-09-11）
- https://github.com/boardgameio/boardgame.io ：MIT，参考房间凭证、回合/阶段和玩家可见状态设计。
- https://github.com/glink25/Parti ：PolyForm Noncommercial，参考邀请/恢复体验；不复制源码，保留服务端权威模型。
- https://github.com/onestraw/doudizhu ：MIT，Python牌型引擎，参考牌型分组、相同长度比较及多解释牌型边界；不引入Python运行时。
- https://github.com/zouchenzhen/party-games-online ：产品资料仓库，参考私密看词流程，不视为可复用游戏源码。
- https://github.com/fept-2024/Fight-the-Landlord ：README将多种牌型校验列为待完善，不适合作为完整规则基础。
