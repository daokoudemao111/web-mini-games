# 单人扫雷设计

用户已确认经典单人方案（2026-09-18）。现有项目内新增，不重建项目。

- 大厅增加扫雷卡片及1人筛选，直接进入/minesweeper，无昵称和房间。
- 简单9×9/10雷、中等16×16/40雷、困难30×16/99雷；经典随机雷盘，不保证无需猜测。
- 第一次实际翻格时布雷，该格及邻居无雷。空白区域自动展开，旗帜保护格子。翻开所有非雷格胜利；踩雷立即结束。
- 左键翻格、右键插旗；手机显式翻格/插旗模式。点击已展开数字在邻旗数量匹配时展开其余邻格，错误旗帜可导致踩雷。提供说明及键盘F插旗。
- 计时从首次翻格开始直到胜负结束；离开页面期间仍计时。时间与难度最快胜利纪录保存本机，不做排行。
- 保存完整当前局及版本号，每次操作更新；恢复校验数据，损坏时安全回到新局并告知。不能存储时仍可玩并提示。
- 手机保持格子可点，大棋盘放在可横向滚动区域。沿用网站配色、图标比例；不改变多人游戏和三国杀下架策略。

实现边界：纯规则lib/minesweeper.ts；本机存储lib/minesweeper-storage.ts；客户端页面app/minesweeper/page.tsx及独立CSS；catalog明确单人与房间游戏分离，API拒绝扫雷房间请求。
验收：首击安全/雷数/展开/旗帜/数字展开/胜负锁定/计时/损坏存档测试，类型检查，生产构建，独立实例页面与多人房间回归，部署前备份。
