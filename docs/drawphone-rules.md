# 画画传话

## 玩法

- 3～6人，独立游戏入口；每人发起一本画册，所有人同时创作。
- 第1轮写一句话，之后画图、猜图交替。每本画册按随机固定顺序经过每位玩家一次，共进行与人数相同的轮数。
- 每轮只能看到上一位留下的内容。文字最多30字、45秒；绘画90秒。
- 可换一句灵感，文字草稿自动保存；画板支持颜色、粗细、橡皮、撤销上一段和清空。
- 点击完成后不能修改；绘画需等待上传完成才可提交。全员完成立即进入下一轮，超时提交服务器已保存的内容，空白注明未完成。
- 创作结束后由房主带大家逐条揭晓，可发送三种表情。全部揭晓后自由翻阅所有画册。不设积分与输赢。
- 房主可提前结束回准备阶段。返回准备或删除房间会清空本局画册，不提供永久相册。

## 同步与恢复

沿用约1.2秒轮询。文字草稿和未上传画笔操作暂存在原浏览器，网络恢复时重试；断线超过本轮期限，未上传内容不会补写进已传出的画册。请留意保存提示。
画作权限由服务器校验，知道画板地址也不能提前查看其他画册；提交后禁止写入，揭晓进度由服务器统一维护。
