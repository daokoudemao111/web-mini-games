# 单人扫雷

## 开始
大厅选择扫雷直接开玩，不需要昵称、房间或其他玩家。人数筛选新增1人。
简单9×9格/10雷，中等16×16格/40雷，困难30列×16行/99雷。

## 规则与操作
- 首次实际翻格时随机布雷，所点格及周围八格无雷；不会因为插旗开始计时。
- 数字表示周围八格的雷数，空白自动展开相连安全区域。
- 左键翻格、右键插旗或取消。手机使用翻格/插旗模式；中等和困难棋盘可横向滚动。
- 翻格模式下点击已展开的数字，周围旗帜数量与数字相同时会展开其他邻格；旗帜位置错误仍可能踩雷。
- 翻开所有非雷格即获胜，无需插完旗；踩雷立即结束并展示雷与错误旗帜。结束后棋盘锁定，可以重新开始。
- 键盘方向键移动焦点，Enter/空格按当前模式操作，F插旗，Home/End移动到本行两端。
- 经典随机雷盘，首击之后不保证所有局面可纯靠推理解决。

## 存档与计时
首次翻格开始计时，胜负后停止。离开页面仍计时。
每次操作保存当前棋盘、时间和各难度最佳胜利用时，保存在当前浏览器当前域名的localStorage，不上传服务器。
刷新或重新进入自动恢复；切换浏览器/域名或清理网站数据无法继承记录。存档损坏时提示并创建新局，保存受限时提示但不阻止继续游戏。
重新开始或切换难度时，进行中的棋盘会先请求确认。刷新不重置计时。
