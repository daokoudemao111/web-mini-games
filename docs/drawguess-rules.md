# 你画我猜

## 已确认规则
- 独立游戏入口，2～6人；房主选择每人画1题或2题。
- 按座位轮流作画；画手15秒内从3个词中选1个，超时选第1个。
- 每题绘画90秒。服务器收到并成功确认的正确猜测按顺序获得100、80、60、40、20分；每位猜词者每题只得分一次。画手每有一位玩家猜中得20分。
- 猜错内容公开；猜对只显示名次和得分，答案在揭晓前对其他猜词者保密。
- 显示字数，最后30秒显示类别提示。仅接受词库明确列出的别称，忽略空白与标点。
- 全员猜中或超时后揭晓8秒，自动换人；全部题目结束后排名，可查看本局画作。最高分相同显示平局。
- 房主可提前结束本局并返回准备阶段；未结束的局不计入累计分。

## 画板与同步
- 白底800×500画布；8种颜色、3种笔触、橡皮、撤销、清空确认。
- 自己落笔即时显示；其他人约每1.2秒拉取新增笔画。实际延迟取决于网络。
- 笔画独立存储在drawing_boards，房间同步不携带完整图片。增量游标遇到撤销/清空后自动重置。
- 每次笔画操作有唯一编号，失败重试不会重复落笔。未确认上传的笔画在浏览器本地暂存；本轮内刷新后重试。服务器截止后不接受迟到笔画。
- 服务器按当前房间成员、画手、题目和截止时间校验画板写入；历史画作只允许本局成员读取。
- 截止时间由服务器决定，访问房间时推进超时状态。所有人关闭页面后不运行后台定时任务，回来后继续推进。
- 新表及清理触发器在首次使用画板时自动创建，也可执行drizzle/0001_drawing_boards.sql。返回准备阶段或删除房间时清理该房间的画作。不会删除三国杀房间或状态。
- 限制单笔200个点、单题2500段笔画、画板JSON约900KB，避免异常输入使存储无限增长。
